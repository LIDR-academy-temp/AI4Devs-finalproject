# Plataforma — HTML/CSS/JavaScript sin framework

- Usar etiquetas semánticas, navegación y botones reales; evitar JS para comportamiento nativo innecesario.
- Emplear CSS variables coherentes y diseño responsive sin inventar nuevos breakpoints si existen.
- Evitar estilos inline repetidos y dependencias remotas no autorizadas.
- Manejar validación y mensajes accesibles con foco correcto.
- Para animaciones aplicar `prefers-reduced-motion`.
- Probar offline antes de declarar autonomía del HTML.
- Nunca insertar secretos en el cliente ni confundir la simulación local con persistencia real.
