# Tasks — web-import

Issue #6 (recorte del 18-oct) y smoke E2E de #7. Rama: `feat/web-import`, creada desde `feature/entrega-2-MVP`. Frontend, `e2e/`, una constante en `@recon/shared` y un test de integración del backend; sin cambios de código del backend, API ni esquema. Si una tarea descubre que falta algo en el API, parar y anotarlo en el proposal ("Huecos del API") en lugar de tocar el backend; los issues de seguimiento los abre la persona. Referencias: `specs/import/spec.md` y `specs/web-shell/spec.md` (qué), `design.md` D1–D13 (cómo). Orden test-first: en cada grupo los tests se escriben y se ven fallar (rojo) antes del código; en verde, se rompe el código a propósito una vez para comprobar que el test lo detecta, y se restaura. Textos de interfaz en inglés y en `features/imports/strings.ts`. La base y la aplicación las levanta la persona con `! pnpm db:up`, `! pnpm db:seed` y `! pnpm dev` dentro de la sesión cuando un grupo las necesita (grupos 1, 9 y 10).
