# Propuesta React + TypeScript para VES

## Propósito

Definir una ruta gradual para modernizar el módulo de documentos de VES sin reemplazar de una vez la aplicación ASP.NET Web Forms existente.

## Resultado esperado

Construir una nueva experiencia para documentos con:

- React
- TypeScript
- API HTTP desacoplada
- contratos JSON documentados
- acceso controlado al modelo documental existente
- pruebas automatizadas desde el primer flujo

## Orden de lectura

1. `01-alcance-y-principios.md`
2. `02-arquitectura-objetivo.md`
3. `03-frontend-react-typescript.md`
4. `04-backend-api.md`
5. `05-plan-paso-a-paso.md`
6. `06-manejo-y-mantenimiento-de-comentarios.md`

## Fuera de alcance inicial

- reescribir todo VES
- migrar inmediatamente la base de datos
- construir un Kanban
- eliminar Web Forms antes de validar la nueva experiencia
- modificar producción durante la etapa de documentación
