Rule sets belong to a provider; each account is linked to one set (or to none, falling back to the global defaults). A rule in a set overrides a global one with the same pattern. Changing a set applies to every account linked to it, without touching imports already analysed. Interpretation rules (derived status, related rows, reported fees) are a separate roadmap screen.
