# Spec Delta

## ADDED Requirements

### Requirement: The app shell navigates between Test Cases and Executions
The signed-in app shell SHALL offer navigation to the Test Cases screen and the Executions screen, and indicate which one is current.

#### Scenario: Navigating to Executions
- **WHEN** a signed-in project member selects Executions in the shell's navigation
- **THEN** the Executions screen is shown and marked as the current screen
